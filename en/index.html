How I work

Four rules I do not negotiate.

  1. 01

    Rules live in the database

    Who can see what is decided by Row Level Security, not by an if statement forgotten in the UI. If the interface gets it wrong, the data stays protected.

  2. 02

    Money does not accept “almost”

    Server-side pricing, idempotent webhooks, refunds with a unique key. Anything involving payments is written to survive double clicks and bad networks.

  3. 03

    Measure before claiming

    Lighthouse before and after, error against the odometer, accessibility audited per route. Any number in a report must be reproducible.

  4. 04

    AI as a tool, not the author

    I use Claude Code daily to move faster. The specification, the review, the tests and the decision to ship are mine, and I am accountable for what is live.
