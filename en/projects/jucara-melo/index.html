Context

The client had a single page with photos embedded in the HTML (2.6 MB), no domain of her own and a canonical address pointing to Instagram. The brief was a real overhaul: a new look, new performance, with booking still happening over WhatsApp.

What I built

  • Next.js site with an editorial language: large serif type, prominent photography and discreet animation.
  • Pre-assessment form that composes the WhatsApp message without storing personal data.
  • Local SEO with clinic structured data, custom domain, sitemap and sharing image.
  • Ten intake forms and ten consent forms in PDF, generated by script in the brand identity.

Engineering decisions

  1. 01

    Content is born visible

    In the first version, 31 blocks left the server invisible and only appeared after roughly 650 KB of JavaScript loaded. I moved the entrances to CSS with server components: the HTML arrives readable and animation is an enhancement.

  2. 02

    Animation a phone can handle

    The animation library stays only where it is indispensable, loaded on demand. Heavy blur and blend effects are turned off on touch screens.

  3. 03

    Documents generated, not edited

    Forms and consent documents come out of a script, with the questions in code and the style in a shared module. Change a sentence and everything is regenerated with the same look.

How it was built

Built with Claude Code. The brief with the client, the review rounds and the decision on what goes live were led by me.
