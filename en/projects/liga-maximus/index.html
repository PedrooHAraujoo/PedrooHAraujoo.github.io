Context

What I built

  • Sign-up, login, profile, password reset and image upload.
  • Admin panel with CRUD for teams, rankings and users.
  • Sign-up with approval: users start as pending and only get in once approved.
  • Integration tests for the user routes.

Engineering decisions

  1. 01

    Permissions as data, not code

    Roles and permissions live in tables, and a decorator checks permission on each route. Creating a new role does not require touching code.

  2. 02

    Authentication without shortcuts

    JWT tokens with expiry handling and passwords stored with bcrypt.

How it was built

This is the project where I learned Flask, SQLAlchemy and GitFlow in practice, working in a team with two other developers.
